LIE - POINTS TO REVIEW (FOR DAD)

This note lists the one place where a Bible reference was adjusted, and a couple of
small things worth a glance, while typing the Lie chapter (the four handwritten
sheets). Nothing was changed quietly.


CHANGE MADE (please confirm this is okay)

1. Sheet 2. The point about the Jewish leaders bribing the soldiers who guarded
   the tomb, so they would spread a lie that Jesus' body had disappeared, was
   given the reference "Matthew 27:1, 2, 62-65". Matthew 27:1-2 is the leaders
   deciding to put Jesus to death, and Matthew 27:62-66 is only the posting of the
   guard before the resurrection. The actual bribing of the soldiers, after the
   resurrection, to spread the false "his disciples stole the body" story, is in
   Matthew 28:11-15. So the references were set like this:
      - "They schemed to have Jesus put to death" (Matthew 27:1-2).
      - "They bribed the soldiers... and spread a lie" (Matthew 27:62-66; 28:11-15).
   Please confirm.


KEPT AS DAD WROTE IT (just so you know)

2. Sheet 4. The phrase "deceptive spirit" in the Ahab account was kept as written.
   In the NIV, 1 Kings 22:22-23 calls it a "lying spirit"; the meaning is the same.

3. Sheet 3. The phrase "an operation of error" (for 2 Thessalonians 2:11) was kept
   as written. The NIV reads "a powerful delusion"; again the sense is the same.

4. Sheet 2. "Proverbs 20:19" was kept as written. That verse is about a gossip who
   betrays a confidence; it fits the point about deceitful speech, though if you
   meant a verse more directly about lying (for example Proverbs 12:22, "the LORD
   detests lying lips"), let me know.
